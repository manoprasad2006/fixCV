# FixCV demo script (3 minutes max)

All footage must be original and recorded during the building window
(Oct 27 – Nov 4, 2026). Royalty-free or self-recorded audio only.
Target objects: Hero Splendor / Honda Activa bike chain, or a leaking
water pipe (water only, never gas).

| Time | Shot | On screen / audio |
|---|---|---|
| 0:00–0:15 | Hook: bike chain slipping. Tap the chain; the outline appears and follows the camera. | Title: "FixCV: repair help in your language." |
| 0:15–0:50 | Problem: one sentence on who has no repair help in their language. User speaks the problem in Tamil or Hindi. | Spoken input + transcript shown. |
| 0:50–1:30 | Diagnose: tap the part, speak, copilot answers with numbered steps in that language. | Steps card in Tamil/Hindi; outline tracking the part. |
| 1:30–2:10 | Verify loop: do a step, show the result to the camera, copilot confirms or corrects. | The agentic moment — show a CONFIRM and (if possible) a CORRECTION. |
| 2:10–2:35 | Language switch: new session, speak in English, get an English reply. Briefly show a Tamil or Hindi reply. | Two languages on screen. |
| 2:35–2:50 | Safety: type or speak a gas/electrical case. The hard-stop screen appears in the session language. | Stop screen; no steps generated. |
| 2:50–3:00 | Close: model credits + repo link. | "SAM 3.1 · Muse Voice Transcribe · Muse Spark" + GitHub link. |

Checklist before recording: `.env` has a real key (never show it on screen),
server running, camera permission granted, all three locales loaded, safety
stop verified in each language, captions added in editing.
